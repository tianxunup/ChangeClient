# Chang'e Client 嫦娥客户端
这是一个处于alpha阶段的客户端。它会改变客户端的一些功能让它更好。感谢你的star！

最新发布：*无*

最新快照：`alpha1`

支持版本：26.2

只有对于最新Minecraft正式版的版本会持续获得支持和开发。其它版本不会有除了安全更新以外其他更新。

## 功能
### 船只飞行 `boat_fly`
类型: 布尔值

默认: 关闭(false)

当此功能开启时(true)，你可以在划船时飞翔。你可以改变`boat_speed`和`boat_vertical_speed`来控制船的快慢。

用法: 坐在船上。按跳跃键爬升下降键下降(默认为下方向键，你可以在按键绑定中更改它)。按方向键操控。

### 船只速度 `boat_speed`
类型: 浮点数

默认: 14.0

单位: m/s(0~1024)

此选项影响船的速度。

### 船只竖直速度 `boat_vertical_speed`
类型: Float

默认: 10.4

单位: m/s(0~45)

此选项影响船的竖直速度(按跳远键时上升的速度和按下降键时下降的速度)。

### Air Fly `air_fly`
类型: 布尔值

默认: 关闭(false)

当此功能开启时(true)，你可以像创造模式一样飞翔（注意别摔了）。

## 命令
主命令: `\change`

用法: `\change <id> [value]`
+ `<id>`: **必填**。功能的 ID。
+ `[value]`: **选填**。如果此参数为空，命令将发送功能配置的值。否则它将把配置设置为你输入的值。

## GUI
按`Backspace`来打开GUI(可以在按键绑定中更改)。在GUI中配置功能设置。
